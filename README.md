# Servidor Local Marques Lab

Projeto de transferência e biblioteca local de arquivos entre iPhone, Android, macOS e Windows pela mesma rede Wi-Fi/LAN.

## Objetivo
Eliminar o uso de pendrive para mover fotos, flyers, vídeos, documentos e arquivos de produção entre dispositivos.

## Escopo da V1
- Descoberta automática na rede local
- Envio e recebimento direto entre dispositivos
- Suporte a arquivos grandes
- Pareamento e segurança
- Biblioteca compartilhada autorizada
- Sem dependência de internet na V1

## Roadmap
- Sprint 01: Fundação Multiplataforma
- Sprint 02: Descoberta na Rede Local
- Sprint 03: Transfer Engine
- Sprint 04: Pareamento e Segurança
- Sprint 05: Desktop macOS + Windows
- Sprint 06: Android
- Sprint 07: iPhone / iOS
- Sprint 08: Biblioteca Local + Release V1
